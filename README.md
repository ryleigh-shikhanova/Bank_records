# Records

A simple C++ console application for managing customer records.

This project was built as an exercise in object-oriented programming, file I/O, custom data structures, and basic record management.

## Features

* Add new customer records
* Display all customer records
* Search for customers by ID
* Search for customers by name
* Edit existing records
* Read records from a text file
* Write records back to a file
* Custom list implementation for storing records

## Structure

* `Bank.cpp / Bank.h` — record management and user interface logic
* `CustomerRecord.cpp / CustomerRecord.h` — customer record representation
* `List.cpp / List.h` — custom list implementation
* `Main.cpp` — program entry point
* `Bank.txt` — stored customer data

## Technologies

* C++
* Standard Library
* File I/O
* Visual Studio
